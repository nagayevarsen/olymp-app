# Поиск олимпиад

Быстрое приложение для поиска действующих официальных олимпиад, конкурсов и материалов для подготовки. Для школьников.

## Какую проблему решает

Сведения об олимпиадах разбросаны по разным сайтам, а дедлайны легко пропустить. Здесь каждое событие можно отобрать по классу, предмету и дате. В каждой карточке есть дедлайн, ссылка на официальный источник и дата последней проверки.

## Возможности

- Экран «Закрывается в ближайшие 14 дней» с цветной меткой срочности.
- Фильтры: класс, возраст, период, предмет, тип, формат, стоимость и раздел (Казахстан или международные).
- Карточка события: кнопка регистрации на официальном сайте, условия, задания прошлых лет с выбором периода и материалы для подготовки.
- ИИ-поиск: несколько моделей ищут события параллельно, а код сверяет ответы и проверяет даты на официальных страницах. Без ключей работает на заглушках.
- Вкладка «Мои» и ссылка для переноса сохранённого на другое устройство.
- Устанавливается на телефон и работает без интернета.
- Светлая и тёмная темы.

## Приватность

Регистрации нет. Сохранённые события и условия поиска хранятся только в браузере пользователя, каталог отбирается прямо на устройстве.

## Как устроено

| Часть | Файлы | Что делает |
|---|---|---|
| Сервер | `app.py` | отдаёт страницу и данные |
| Логика дат | `catalog/dates.py`, `static/dates.js` | статусы и срочность по времени Казахстана |
| Данные | `data/`, `catalog/events.py`, `catalog/archives.py` | хранение и проверка записей |
| Интерфейс | `templates/`, `static/app.js`, `static/filters.js` | карточки, форма, отбор |
| Умный поиск | `smart_search/`, `static/smart.js` | модели, сверка ответов, проверка страниц, кэш и лимиты |
| Офлайн | `static/sw.js`, `static/manifest.webmanifest` | работа без интернета и установка |
| Тесты | `tests/`, `.github/workflows/tests.yml` | проверка при каждой отправке кода |

## Запуск на своём компьютере (Windows)

Нужен Python 3.13. Node.js нужен только для проверки логики браузера в тестах.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

Затем откройте http://127.0.0.1:5000

## Проверка

```powershell
.venv\Scripts\python -m pytest          # все тесты
.venv\Scripts\python -m catalog.events  # проверка файлов с данными после правки
```

## Данные

Только факты и ссылки на официальные источники. Тексты, задания и логотипы организаторов не копируются. Записи с пометкой ПРИМЕР выдуманы и нужны для проверки приложения.
